# INT-05 - Instagram

## Objetivo

Conectar cuenta profesional y analizar contenido organico con limites claros.

## Entregables

- Conexion via Meta.
- Media e insights disponibles.
- Snapshots de cuenta.
- Entrada manual de reels/posts ganadores de seguidores.

## Criterios de cierre

- No se promete seguidores por post via API.
- Rankings usan metricas soportadas.
- URLs/media se refrescan segun caducidad.
