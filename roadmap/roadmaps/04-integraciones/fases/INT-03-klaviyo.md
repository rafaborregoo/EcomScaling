# INT-03 - Klaviyo

## Objetivo

Incorporar retencion y email marketing al producto.

## Entregables

- OAuth/API auth segun decision final.
- Account, lists, segments, flows, campaigns, forms.
- Reporting API por periodos.
- Conversion metric configurable.
- Rate limit handling.

## Criterios de cierre

- Revenue/email y flows se calculan con fuente clara.
- Alertas de flow/campana pueden basarse en datos reales.
