# Decisiones y seguimiento

## Objetivo

Centralizar decisiones, riesgos, preguntas abiertas y estado de avance.

## Archivos

- `ADR_LOG.md`: decisiones arquitectonicas y de producto.
- `RIESGOS.md`: riesgos activos, impacto, mitigacion y propietario.
- `PREGUNTAS_ABIERTAS.md`: dudas que bloquean o cambian alcance.
- `ESTADO_GLOBAL.md`: estado resumido por dominio y fase.
