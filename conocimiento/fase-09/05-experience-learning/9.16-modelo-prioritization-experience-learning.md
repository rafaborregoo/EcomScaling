# 9.16 — Priorización en Experience / Learning

## Cadena conceptual

```text
PROBLEM SET
↓
PRIORITY DECISION
↓
SELECTED INTERVENTION
↓
OUTCOME
↓
REMAINING GAP
↓
NEW BOTTLENECK
↓
LEARNING
```

## Cada experiencia debe conservar

- selected problem;
- alternatives;
- expected impact;
- urgency;
- bottleneck hypothesis;
- opportunity cost;
- outcome;
- remaining gap;
- bottleneck migration;
- prioritization quality.

## Learnings posibles

- impact systematically overestimated;
- urgency overweighted;
- specific constraints repeatedly dominate;
- certain interventions produce low remaining-gap reduction;
- bottleneck migration follows recurrent patterns.

## Regla

El Learning Engine debe mejorar el sistema de priorización futuro, no solo registrar qué acciones produjeron uplift.
