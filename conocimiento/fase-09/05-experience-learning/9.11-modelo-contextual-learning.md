# 9.11 — Modelo Contextual Learning en Experience / Learning

## Relación conceptual

```text
EXPERIENCE
↓
CONTEXT
↓
OUTCOME
↓
CONDITIONAL LEARNING
```

## El learning debe conservar

- source context;
- relevant dimensions;
- outcome;
- moderators;
- interaction effects;
- evidence;
- context-specific confidence.

## Evolución

Nueva evidencia puede:

- reinforce same context;
- create new context;
- reveal moderator;
- split learning;
- merge compatible learnings;
- contradict a context-specific rule.

## Context drift

Cuando cambia el tenant, debe revisarse la relevancia de learnings históricos.

## Regla

La experiencia debe aprender no solo “qué ocurrió”, sino “en qué contexto ocurrió y bajo qué condiciones”.
