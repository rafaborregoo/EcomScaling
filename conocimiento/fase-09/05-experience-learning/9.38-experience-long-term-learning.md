# 9.38 — Experience / Learning de Long-Term Learning

Debe conservarse historia dinámica sobre:

## Revalidation history
- knowledge;
- review;
- evidence;
- result;
- confidence change.

## Structural break history
- break;
- affected learnings;
- reclassification;
- later outcomes.

## Reactivation history
- dormant knowledge;
- returned context;
- reactivation;
- outcome.

## Consolidation history
- source items;
- consolidated representation;
- compression decisions.

## Memory quality
Puede evaluar:
- stale knowledge incidents;
- unnecessary retention;
- useful memory lost;
- duplication.

## Meta-learning
Puede aprender qué domains tienen mayor half-life, recurrence o structural sensitivity.

## Regla
El sistema debe aprender también qué merece ser recordado a largo plazo.
