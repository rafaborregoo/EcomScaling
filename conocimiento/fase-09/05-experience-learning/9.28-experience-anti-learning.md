# 9.28 — Experience / Learning de Anti-Learning

## Objetivo

Conservar historia sobre evidencia rechazada, errores de aprendizaje y procesos de corrección.

## 1. Rejected Evidence

Debe registrar:

- evidence;
- reason;
- contamination;
- reviewer;
- later outcome.

## 2. Quarantined Learning

Debe conservar:

- candidate;
- uncertainty;
- missing evidence;
- conditions for release.

## 3. False Learning Incident

Cuando un learning previamente aceptado resulta erróneo:

- registrar causa;
- affected decisions;
- propagation;
- correction;
- lessons.

## 4. Bias History

Puede aprender dónde aparecen repetidamente:

- selection bias;
- measurement error;
- confirmation bias;
- proxy failure.

## 5. Anti-Learning Effectiveness

Puede evaluar:

- falsos positivos evitados;
- candidates correctamente rechazados;
- over-rejection;
- under-rejection.

## 6. Reinstatement

Una evidencia rechazada puede ser reconsiderada si cambian:

- quality;
- context;
- corroboration.

## 7. Meta-learning

Puede aprender qué tipos de evidencia requieren mayor escrutinio.

## Regla

El sistema debe aprender también de sus errores epistemológicos.
