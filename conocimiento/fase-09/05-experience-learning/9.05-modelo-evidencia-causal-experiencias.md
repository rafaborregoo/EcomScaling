# 9.05 — Modelo conceptual de evidencia causal en experiencias

## Objetivo

Definir qué información dinámica debe conservar EcomScaling IA cuando una intervención real produce una experiencia utilizable para aprendizaje futuro.

## Unidad mínima de experiencia causal

Una experiencia debería poder vincular:

```text
intervention
→ context
→ baseline
→ outcome
→ counterfactual
→ estimated_effect
→ evidence_strength
→ learning
```

## Información relevante

### Intervención

Qué se hizo realmente.

### Contexto

En qué condiciones se ejecutó.

### Baseline

Cuál era el estado previo o referencia.

### Outcome

Qué ocurrió.

### Contrafactual

Cómo se estimó lo que habría ocurrido sin la intervención.

### Efecto

Qué parte del resultado se considera incremental.

### Fuerza de evidencia

Qué confianza merece la inferencia.

### Limitaciones

Qué factores impiden generalizar directamente.

## Learning

Un learning derivado de una experiencia causal no debería reducirse a:

```text
"X funciona"
```

Debe conservar condiciones de aplicabilidad.

Ejemplo conceptual:

```text
En tiendas con contexto C,
la intervención X mostró evidencia compatible con mejora Y,
bajo condiciones Z,
con nivel de evidencia E.
```

## Promoción de aprendizaje

Una experiencia aislada no debe convertirse automáticamente en conocimiento general.

La promoción debe considerar:

- repetición;
- consistencia;
- comparabilidad de contextos;
- calidad causal;
- evidencia contradictoria;
- límites de generalización.

## Contradicción

Si dos experiencias comparables producen resultados incompatibles, el sistema debe conservar la contradicción.

No debe sobrescribir automáticamente la experiencia anterior.

## Decay

La utilidad de una experiencia puede reducirse si:

- cambia el canal;
- cambia la plataforma;
- cambia el mercado;
- cambia el comportamiento del cliente;
- cambia la oferta;
- cambia el contexto competitivo.

## Regla

El aprendizaje operativo debe conservar la cadena:

```text
learning
→ supporting experiences
→ supporting evidence
```

para evitar conocimiento sin trazabilidad.
