# 9.31 — Experience / Learning de Explainability

## Objetivo

Conservar experiencia sobre calidad y utilidad de las explicaciones.

## 1. Explanation History

Debe registrar:

- explanation version;
- learning version;
- audience;
- evidence basis;
- usage.

## 2. Explanation Review

Puede conservar:

- accepted;
- challenged;
- corrected;
- insufficient;
- misleading.

## 3. Correction History

Si una explanation fue incorrecta:

- reason;
- missing evidence;
- stale version;
- correction.

## 4. Explainability Effectiveness

Puede aprender qué explicaciones:

- facilitan review;
- detectan contradicciones;
- reducen errores;
- generan confusion.

## 5. Explanation Debt

Puede detectarse knowledge importante sin explanation suficiente.

## 6. Meta-learning

Puede aprender qué tipos de learning requieren mayor profundidad explicativa.

## Regla

El sistema puede mejorar cómo explica sin alterar la evidencia subyacente.
