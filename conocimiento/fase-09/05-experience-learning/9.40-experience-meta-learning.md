# 9.40 — Experience / Learning de Meta-Learning

## Debe conservarse

### Calibration History
- expected confidence;
- actual result;
- domain;
- correction.

### Process Change History
- proposed change;
- approved change;
- previous behavior;
- new behavior;
- observed effect.

### Error History
- recurrent error types;
- root causes;
- downstream impact.

### Blind Spot History
- missing domains;
- missing outcomes;
- later resolution.

### Review Effectiveness
- false approvals;
- false rejections;
- unnecessary reviews;
- missed escalations.

### Meta-Rule History
- creation;
- promotion;
- degradation;
- supersession;
- invalidation.

## Regla

El sistema debe conservar evidencia de cómo sus propias reglas de aprendizaje han evolucionado.
