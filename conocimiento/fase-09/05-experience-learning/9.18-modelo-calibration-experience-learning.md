# 9.18 — Calibration en Experience / Learning

## Cadena conceptual

```text
BENCHMARK / GUARDRAIL / THRESHOLD
↓
DECISION
↓
OBSERVED EVENT
↓
CLASSIFICATION
↓
CALIBRATION LEARNING
```

## Experiencias relevantes

- true positive;
- false positive;
- true negative;
- false negative;
- near miss;
- prevented incident;
- unnecessary review;
- delayed execution.

## Learnings posibles

- threshold too strict;
- threshold too permissive;
- benchmark invalid for context;
- guardrail correctly prevented harm;
- escalation point too low/high;
- context condition missing.

## Version learning

```text
v1
→ evidence
→ v2
→ evidence
```

Debe poder evaluarse si la nueva calibración mejora el sistema.

## Regla

La experiencia alimenta recomendaciones de calibración, no cambios autónomos de authority.
