# 9.06 — Modelo de confounding para Experience / Learning

## Objetivo

Evitar que EcomScaling IA aprenda reglas generales a partir de experiencias cuya causalidad está contaminada.

## Cada experiencia debería poder conservar

```text
intervention
outcome
timeline
concurrent_interventions
candidate_confounders
mix_changes
tracking_changes
evidence
confounding_assessment
learning
```

## Confounding assessment

Una experiencia debería indicar si el resultado fue:

- razonablemente aislado;
- parcialmente confundido;
- materialmente confundido;
- imposible de aislar.

## Learning confidence

El nivel de confounding debe afectar a la confianza del learning.

```text
resultado positivo
+
confounding severo
→
learning confidence bajo
```

## Contradictory evidence

Una experiencia con menor confounding puede tener mayor peso que varias experiencias observacionales débiles.

La cantidad de experiencias no debe sustituir la calidad causal.

## Generalización

Antes de reutilizar un learning debe revisarse si los factores que actuaron como confounders están presentes, ausentes, cambiaron o no pueden observarse.

## Timeline histórica

La plataforma debería poder reconstruir qué otras acciones estaban activas cuando se generó un outcome.

## Regla

Un learning debe conservar la evaluación de confounding que existía cuando fue derivado.
