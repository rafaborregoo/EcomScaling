# 9.10 — Generalization Boundary en Experience / Learning

## Relación conceptual

```text
LEARNING
↓
SOURCE CONTEXT
↓
GENERALIZATION BOUNDARY
↓
SUPPORTED USE
```

## Boundary dinámico

Puede:

- expand;
- contract;
- split;
- become disputed.

## Evidencia nueva

Una experiencia en un nuevo contexto puede:

```text
confirm portability
```

```text
reveal moderator
```

```text
create exclusion condition
```

```text
contradict prior boundary
```

## Boundary history

Debe conservarse:

- previous scope;
- new scope;
- evidence trigger;
- reason;
- timestamp.

## Regla

Un learning no debe almacenarse como una afirmación descontextualizada; debe permanecer unido a los límites donde la evidencia lo soporta.
