# 9.36 — Experience / Learning de Global vs Tenant Knowledge

## Objetivo

Conservar experiencia sobre cómo interactúan priors globales y evidencia local.

## 1. Prior Accuracy

Debe registrar cuándo global/cohort prior:

- acertó;
- falló;
- necesitó adaptation.

## 2. Local Override History

Debe conservar:

- base claim;
- local evidence;
- override;
- outcome;
- later review.

## 3. Global Mismatch Patterns

Puede aprender qué types de tenants contradicen knowledge global.

## 4. Promotion History

Debe registrar local learnings que:

- quedaron locales;
- pasaron a cohort;
- llegaron a global candidate.

## 5. Reversion History

Si local exception deja de aplicar:

- registrar reason;
- restore prior weighting;
- preserve history.

## 6. Meta-learning

Puede aprender cuándo confiar más en:

- global prior;
- cohort prior;
- local evidence.

## Regla

El Learning Engine debe aprender cómo ponderar sus capas de conocimiento, sin romper sus scopes.
