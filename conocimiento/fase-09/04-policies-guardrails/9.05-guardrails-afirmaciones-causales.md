# 9.05 — Guardrails para afirmaciones causales

## Propósito

Evitar que el sistema presente como causal una evidencia que solo es descriptiva, asociativa o atribuida.

## Regla dura 1 — No causalidad automática

Nunca convertir automáticamente:

```text
correlación
```

```text
secuencia temporal
```

```text
atribución de plataforma
```

en:

```text
causalidad confirmada
```

## Regla dura 2 — No incrementalidad inventada

Si no existe un contrafactual razonable, el sistema no debe inventar:

- uplift incremental;
- revenue incremental;
- conversiones incrementales;
- ROI incremental.

## Regla dura 3 — Incertidumbre obligatoria

Cuando la evidencia no permita una conclusión fuerte, la salida debe expresarlo explícitamente.

## Regla dura 4 — Precisión proporcional

La precisión numérica de una estimación no debe transmitir una certeza superior a la que permite la metodología.

## Regla dura 5 — Escalado condicionado

Una recomendación de escalado material basada en causalidad débil debe requerir:

- experimentación adicional;
- rollout limitado;
- supervisión humana;
- o evidencia reforzada.

La alternativa concreta dependerá del riesgo.

## Regla dura 6 — Separación semántica

El sistema debe preservar la diferencia entre:

```text
observed
attributed
estimated_incremental
causal_supported
```

No deben colapsarse en una sola categoría.

## Regla dura 7 — No ocultar limitaciones

Una conclusión causal debe conservar sus caveats relevantes.

No se permite eliminar incertidumbre únicamente para hacer la recomendación más contundente.
