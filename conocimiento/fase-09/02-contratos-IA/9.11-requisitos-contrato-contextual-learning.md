# 9.11 — Requisitos conceptuales para Contextual Learning Contract

## Objetivo

Definir qué información debe poder intercambiar el sistema para representar learnings dependientes del contexto.

## Learning

- learning reference;
- claim;
- version.

## Context

Debe poder representar dimensiones relevantes como:

- AOV;
- margin;
- maturity;
- business model;
- market;
- channel;
- product;
- customer segment;
- inventory conditions;
- lifecycle conditions.

## Conditional effect

Debe poder expresar:

- context;
- outcome;
- effect direction;
- effect magnitude si existe;
- evidence;
- confidence.

## Moderators

Debe poder representar:

- moderator;
- observed interaction;
- direction;
- evidence.

## Context states

Debe ser posible distinguir:

```text
SUPPORTED
CONTRADICTED
UNKNOWN
NOT_APPLICABLE
```

## Learning structure

Debe permitir:

- split learning;
- merged learning;
- parent/general learning reference;
- contextual child learning reference.

## History

Debe poder conservar:

- context changes;
- split/merge events;
- new moderators;
- confidence changes.

## Regla

El contrato no debe obligar a representar un único efecto global cuando la evidencia soporte efectos distintos por contexto.
