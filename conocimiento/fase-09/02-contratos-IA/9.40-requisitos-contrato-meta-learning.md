# 9.40 — Requisitos conceptuales de contrato para Meta-Learning

## Objetivo

Definir qué información debe representarse para aprender sobre el learning process.

## Learning Process Observation
- domain;
- stage;
- input;
- output;
- duration;
- result.

## Error Classification
- error type;
- stage;
- severity;
- root cause;
- downstream impact.

## Calibration
- predicted confidence;
- observed reliability;
- sample scope;
- calibration state.

## Meta-Rule
- rule;
- scope;
- rationale;
- evidence;
- version;
- confidence.

## Learning Quality
- correctness;
- stability;
- usefulness;
- generalization;
- cost.

## Learning Efficiency
- evidence cost;
- review effort;
- latency;
- useful output.

## Blind Spot
- domain;
- missing evidence;
- missing outcome;
- uncertainty;
- risk.

## Meta-Review
- trigger;
- proposed process change;
- expected effect;
- governance requirement.

## Meta-Outcome
- process change;
- observed result;
- rollback state.

## Provenance
Debe enlazar el meta-learning con los learning episodes que lo originaron.

## Regla crítica
Debe distinguirse:
**meta-learning recommendation**
de
**authorized change to the learning system**.
