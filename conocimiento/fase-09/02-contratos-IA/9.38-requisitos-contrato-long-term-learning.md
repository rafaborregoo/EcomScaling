# 9.38 — Requisitos conceptuales de contrato para Long-Term Learning

Debe poder representarse:

## Memory horizon
- short-lived;
- seasonal;
- medium-term;
- long-lived;
- structural.

## Temporal layer
- episodic;
- operational;
- strategic;
- structural.

## Recurrence
- pattern;
- cycle;
- last occurrence;
- confirmation count.

## Regime
- regime identity;
- characteristics;
- effective period;
- transition reason.

## Structural break
- type;
- affected knowledge;
- previous regime;
- new regime;
- review state.

## Consolidation
- source episodes;
- source learnings;
- consolidated knowledge;
- compression rationale.

## Revalidation
- last confirmation;
- next review;
- trigger;
- result;
- confidence change.

## Memory state
- active;
- dormant;
- reactivated;
- degraded;
- historical;
- retired.

## Longitudinal confidence
Debe considerar temporal span, recurrence, stability, contradictions y revalidation history.

## Retention boundary
Debe representar privacy, legal retention, deletion y tenant isolation.

## Regla crítica
Memory age nunca sustituye validity.
