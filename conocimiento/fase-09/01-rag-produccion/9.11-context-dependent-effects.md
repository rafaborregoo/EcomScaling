# 9.11 — Context-dependent effects

## Principio

El efecto de una intervención puede cambiar según el contexto.

```text
SAME INTERVENTION
+
DIFFERENT CONTEXT
=
DIFFERENT POSSIBLE EFFECT
```

Ejemplos relevantes:

```text
HIGH-AOV ≠ LOW-AOV
NEW STORE ≠ MATURE STORE
SUBSCRIPTION ≠ ONE-OFF
HIGH MARGIN ≠ LOW MARGIN
DTC ≠ MARKETPLACE
```

## Contexto

Puede incluir:

- AOV;
- margin;
- maturity;
- business model;
- market;
- channel;
- customer segment;
- product;
- inventory;
- lifecycle.

## Regla

El learning debe conservar las condiciones bajo las que el efecto fue observado.
