# 9.11 — Conditional Learning

## Definición

Un learning contextual debe poder expresarse de forma condicional.

Ejemplo conceptual:

```text
IF:
business model = DTC
maturity = mature
inventory = stable

THEN:
learning X has supporting evidence
```

La forma lógica exacta no implica una implementación concreta.

## Context-specific confidence

Puede existir:

```text
HIGH confidence → context A
MEDIUM confidence → context B
UNKNOWN → context C
```

## Split learning

Cuando un learning agregado oculta efectos distintos, debe dividirse por contexto.

## Merge learning

Solo cuando múltiples contexts muestran comportamiento suficientemente consistente y no existen moderators materiales.

## Regla

La IA debe preferir learnings condicionados correctos antes que reglas globales simples pero falsas.
