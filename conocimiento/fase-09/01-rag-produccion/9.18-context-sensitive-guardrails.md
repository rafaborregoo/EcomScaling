# 9.18 — Context-Sensitive Guardrails

Los guardrails pueden necesitar diferente calibración según:

- risk;
- reversibility;
- financial exposure;
- maturity;
- scale;
- AOV;
- margin;
- channel;
- automation level.

## Capas posibles

```text
warning
→ review
→ hard block
```

## Riesgo de underfitting

Un mismo threshold para contextos materialmente distintos.

## Riesgo de overfitting

Crear demasiadas reglas ultraespecíficas con poca evidencia.

## Regla

Usar la mínima complejidad necesaria para representar diferencias reales de riesgo.
