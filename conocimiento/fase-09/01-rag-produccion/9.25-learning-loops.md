# 9.25 — Learning Loops

## Definición

Un Learning Loop es un ciclo cerrado que conecta:

**context → decision → action → outcome → evaluation → learning → future decision**

## Principios

- Guardar outcomes no equivale a aprender.
- El loop debe conocer qué se recomendó y qué se ejecutó.
- La evidencia solo puede cerrar el loop cuando el outcome ha madurado.
- Un loop cerrado no implica promoción automática de conocimiento.
- Un loop puede reabrirse.
- La traceability es esencial.

## Estados conceptuales

- initiated;
- awaiting execution;
- executing;
- awaiting outcome;
- immature;
- evaluable;
- learned;
- applied;
- reopened;
- invalidated.

## Regla

Un sistema aprende de verdad cuando la experiencia modifica decisiones futuras de forma trazable.
