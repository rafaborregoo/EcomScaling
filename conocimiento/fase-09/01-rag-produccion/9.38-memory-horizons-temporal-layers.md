# 9.38 — Memory Horizons y Temporal Layers

## Memory horizons
- short-lived;
- seasonal;
- medium-term;
- long-lived;
- structural.

## Temporal layers
- episodic;
- operational;
- strategic;
- structural.

## Principios
- Cada tipo de knowledge decae a distinta velocidad.
- Seasonal knowledge puede pasar a dormant.
- Structural knowledge puede durar más, pero sigue siendo revisable.
- Review cadence debe depender de volatility y risk.

## Regla
Retention y revalidation deben adaptarse a la naturaleza temporal del learning.
