# 9.25 — Loop Closure y calidad

## Loop Closure

Cerrar un loop exige conectar:

- recomendación;
- ejecución;
- outcome;
- evaluación;
- learning.

## Loop Completeness

Debe comprobar:

- contexto;
- intervention identity;
- execution status;
- outcome;
- maturity;
- attribution;
- evidence quality.

## Loop Quality

Depende de:

- observability;
- traceability;
- execution fidelity;
- outcome fidelity;
- attribution;
- context completeness.

## Principio

Un loop incorrectamente cerrado puede generar peor aprendizaje que un loop correctamente marcado como inconcluso.
