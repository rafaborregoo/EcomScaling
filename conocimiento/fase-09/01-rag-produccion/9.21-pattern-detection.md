# 9.21 — Pattern Detection

## Definición

Pattern Detection identifica regularidades recurrentes entre contexto, intervención, secuencia, comportamiento, outcome, riesgo o fricción.

## Principios

- Repetición no equivale a causalidad.
- Un patrón debe conservar condiciones de aplicabilidad.
- Las coincidencias tempranas deben tratarse como pattern candidates.
- La detección debe incluir evidencia favorable y contradictoria.
- Los patrones deben poder degradarse o invalidarse.
- La frecuencia no sustituye fuerza de evidencia.
- El contexto no debe colapsarse en una conclusión global.

## Tipos

- outcome patterns;
- context patterns;
- failure patterns;
- friction patterns;
- sequence patterns;
- human-response patterns;
- channel patterns;
- cohort patterns;
- temporal patterns;
- incident patterns.

## Regla

El Pattern Detection descubre regularidades.

No decide por sí mismo que sean causales, universales o normativas.
