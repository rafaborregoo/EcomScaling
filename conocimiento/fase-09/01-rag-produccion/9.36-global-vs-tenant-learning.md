# 9.36 — Global Knowledge vs Tenant-Specific Learning

## Global Knowledge

Conocimiento reusable y suficientemente estable para múltiples tenants.

## Tenant-Specific Learning

Conocimiento validado dentro del contexto de una tienda concreta.

## Principios

- Global knowledge actúa como prior.
- Local evidence actualiza ese prior.
- Tenant knowledge tiene scope local por defecto.
- Una señal local no invalida automáticamente knowledge global.
- Global no significa universal.
- Scope debe acompañar a todo knowledge.

## Regla

El sistema debe poder decir: “esto suele funcionar globalmente, pero no en este tenant”.
