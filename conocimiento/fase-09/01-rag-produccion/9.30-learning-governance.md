# 9.30 — Learning Governance

## Definición

Learning Governance es el conjunto de reglas, roles y procesos que controlan cómo los aprendizajes pueden validarse, promoverse, aplicarse, degradarse o retirarse.

## Principios

- Learning no equivale a authority.
- La experiencia puede informar governance.
- El Learning Engine no puede modificar por sí mismo policies, trust boundaries o permisos.
- El nivel de governance debe depender de risk y scope.
- Low-risk learning puede automatizarse dentro de límites.
- High-impact changes requieren revisión o aprobación.

## Regla

El sistema puede aprender continuamente sin tener autoridad continua para cambiarse a sí mismo.
