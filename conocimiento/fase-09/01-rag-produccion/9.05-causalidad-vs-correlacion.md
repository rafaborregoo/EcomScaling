# 9.05 — Causalidad vs correlación

## Definición

La correlación indica asociación entre variables.

La causalidad implica que una intervención sobre una variable modifica un resultado respecto a lo que habría ocurrido sin esa intervención.

## Regla de interpretación

```text
correlación
≠
causalidad
```

Observar que dos métricas cambian juntas no demuestra:

- dirección causal;
- magnitud del efecto;
- incrementalidad;
- ausencia de otras causas.

## Jerarquía útil de afirmaciones

### Descriptiva

```text
La conversión pasó de 2,1 % a 2,5 %.
```

### Asociativa

```text
La mejora coincide con el lanzamiento de la nueva landing.
```

### Causal plausible

```text
La landing puede haber contribuido, pero el efecto no está aislado.
```

### Causal respaldada

```text
Existe una comparación suficientemente válida para estimar el efecto.
```

## Temporalidad

Una causa debe preceder al efecto.

La temporalidad es necesaria, pero no suficiente para demostrar causalidad.

## Mecanismo

Una hipótesis causal gana plausibilidad cuando existe un mecanismo coherente.

Ejemplo:

```text
landing más clara
→ menor fricción
→ mayor progresión
→ más compras
```

El mecanismo no sustituye la evidencia.

## Anti-pattern principal

```text
ocurrió después
→ por tanto ocurrió por eso
```

Esta inferencia debe rechazarse salvo que exista evidencia adicional.

## Principio de proporcionalidad

Cuanto mayor sea el coste, riesgo o irreversibilidad de una decisión, mayor debe ser la calidad de evidencia requerida para tratar una relación como causal.
