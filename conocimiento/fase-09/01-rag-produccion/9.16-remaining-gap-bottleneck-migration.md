# 9.16 — Remaining Gap y Bottleneck Migration

## Remaining Gap

Representa cuánto problema permanece después de una intervención.

## Saturation

El valor marginal de seguir optimizando una misma palanca puede disminuir.

## Bottleneck Migration

Una mejora puede desplazar la restricción a otra parte del sistema.

## Regla

Después de cada intervención relevante debe reevaluarse:

```text
what remains?
what is now limiting performance?
```

No asumir que la prioridad anterior sigue siendo la correcta.
