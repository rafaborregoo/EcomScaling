# 9.15 — Estados de una recomendación

Distinguir:

```text
accepted recommendation
rejected recommendation
modified recommendation
executed recommendation
non-executed recommendation
recommendation later superseded
```

## Accepted

Aceptada no significa buena.

## Rejected

Rechazada no significa mala.

## Modified

Debe compararse versión original con versión ejecutada.

## Executed

Solo permite evaluación causal si execution fidelity y evidencia son suficientes.

## Non-executed

Puede generar learning sobre feasibility, trust o constraints.

## Superseded

Puede reflejar nueva evidencia o cambio de contexto.

## Regla

El estado operacional de una recomendación no debe confundirse con su calidad.
