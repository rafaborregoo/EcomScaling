# 9.13 — Root Cause, recurrencia y resiliencia

## Trigger vs Root Cause

El trigger inicia el fallo.

La root cause explica por qué el sistema permitió que ocurriera.

## Contributing Factors

Los incidentes pueden ser multicausales.

## Recurrence

La repetición indica que el aprendizaje anterior no fue suficiente o no fue aplicado.

## Resilience

Un sistema resiliente puede:

```text
detect
contain
recover
learn
```

Madurez operacional no significa ausencia total de fallos.

## Regla

Un learning de incidente debe producir tanto corrección inmediata como prevención de recurrencia.
