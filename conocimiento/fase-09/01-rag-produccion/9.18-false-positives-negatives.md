# 9.18 — False Positives, False Negatives y Near Misses

## False Positive

El sistema bloquea o alerta ante una situación que no era materialmente peligrosa.

## False Negative

El sistema deja pasar un riesgo real.

## Near Miss

Existió riesgo real pero no se materializó el daño.

## Prevented Incident

El control evitó una consecuencia adversa.

## Regla

La evaluación debe ponderar:

```text
frequency
+
severity
+
operational cost
```

porque un único false negative grave puede importar más que muchos false positives pequeños.
