# 9.22 — Global Learning vs Tenant-Specific Learning

## Problema

Un aprendizaje global puede ser válido en promedio y fallar de forma consistente en un tenant.

## Principios

- El conocimiento global y tenant-specific pueden coexistir.
- Una excepción local no invalida automáticamente el patrón global.
- El sistema debe reducir applicability cuando un tenant contradice persistentemente el aprendizaje global.
- Cross-tenant contradictions pueden revelar cohorts ocultas.
- La generalización debe depender de evidence coverage.

## Regla

Nunca forzar que el tenant obedezca una conclusión global cuando existe evidencia local sólida en sentido contrario.
