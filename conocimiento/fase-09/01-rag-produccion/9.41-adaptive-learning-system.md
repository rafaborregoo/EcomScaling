# 9.41 — Adaptive Learning System

## Capacidades adaptativas

El sistema debe poder:

- learn;
- abstain;
- validate;
- quarantine;
- promote;
- explore;
- exploit;
- degrade;
- supersede;
- forget;
- revalidate;
- meta-learn.

## Debe adaptarse a

- drift;
- structural breaks;
- tenant context;
- new evidence;
- contradictions;
- operational friction;
- strategic changes.

## Regla

Adaptation must change knowledge state without silently changing authority boundaries.
