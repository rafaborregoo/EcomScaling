# 9.10 — Expansión y contracción del boundary

## Boundary expansion

Ocurre cuando nuevas evidencias validan el learning en contextos adicionales.

```text
context A
→ A + B
→ A + B + C
```

La ampliación debe ganarse mediante evidencia.

## Boundary contraction

Ocurre cuando nueva evidencia muestra que el learning depende de condiciones más estrechas de lo pensado.

## Revalidation

Fuera del boundary:

```text
learning
→ transferred hypothesis
→ validation
→ boundary update
```

## Regla

El Generalization Boundary es dinámico y debe evolucionar con nueva evidencia.
