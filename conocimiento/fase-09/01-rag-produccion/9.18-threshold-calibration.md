# 9.18 — Threshold Calibration

## Definición

Threshold calibration evalúa si un punto de decisión está:

```text
TOO STRICT
WELL CALIBRATED
TOO PERMISSIVE
```

## Too Strict

Puede generar:

- false positives;
- unnecessary reviews;
- delay;
- lost opportunity;
- alert fatigue.

## Too Permissive

Puede generar:

- false negatives;
- incidents;
- near misses;
- excessive exposure.

## Regla

El objetivo no es minimizar alertas ni incidentes de forma aislada, sino equilibrar riesgo y fricción operacional según contexto.
