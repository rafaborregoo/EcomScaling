# 9.39 — Strategic Constraints y Resource Allocation

## Binding Constraint

Es el factor que limita materialmente el crecimiento o rendimiento del sistema.

Puede ser:

- demand;
- conversion;
- margin;
- cash;
- inventory;
- fulfillment;
- team;
- data;
- creative capacity.

## Constraint Migration

Resolver un constraint puede hacer emerger otro.

## Resource Allocation

Debe evaluar:

- expected value;
- opportunity cost;
- capability value;
- risk;
- optionality.

## Regla

La estrategia debe aprender dónde un recurso adicional cambia realmente el sistema.
