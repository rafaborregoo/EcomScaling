# 9.22 — Tenant Context relevante para contradicciones

## Objetivo

Definir qué diferencias específicas de un ecommerce pueden explicar conflictos entre aprendizajes.

## Variables relevantes

### Negocio
- business model;
- maturity;
- scale;
- margin structure;
- AOV;
- repeat rate.

### Oferta
- producto;
- pricing;
- promociones;
- assortment.

### Mercado
- país;
- competencia;
- estacionalidad;
- category dynamics.

### Canal
- paid media;
- email;
- SEO;
- marketplace;
- retail.

### Cliente
- acquisition source;
- lifecycle;
- cohorts;
- customer type.

### Operación
- inventory;
- fulfillment;
- support;
- capacity.

### Datos
- attribution;
- tracking;
- windows;
- quality;
- metric definitions.

### Temporalidad
- campañas;
- lanzamientos;
- cambios estructurales;
- platform migrations.

## Principio

Una contradicción aparente puede desaparecer cuando se incorpora contexto tenant-specific.

## Prohibición

No usar una contradicción local como evidencia suficiente para invalidar conocimiento global.
