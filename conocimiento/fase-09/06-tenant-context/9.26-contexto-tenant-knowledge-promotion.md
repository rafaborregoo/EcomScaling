# 9.26 — Tenant Context relevante para Knowledge Promotion

## Objetivo

Definir qué características de un ecommerce condicionan si un learning local puede generalizarse.

## Contexto relevante

### Modelo de negocio
- DTC;
- marketplace;
- subscription;
- B2B;
- omnichannel.

### Madurez
- early;
- growth;
- mature.

### Economía
- margin;
- AOV;
- CAC;
- LTV;
- repeat rate.

### Canal
- paid;
- CRM;
- marketplace;
- SEO;
- retail.

### Producto
- category;
- price point;
- replenishment;
- seasonality.

### Mercado
- geography;
- competition;
- demand profile.

### Operación
- inventory;
- fulfillment;
- support;
- capacity.

### Datos
- tracking;
- attribution;
- quality;
- history depth.

## Principio

Cuanto más depende un learning de particularidades del tenant, menor debe ser su promotion scope inicial.

## Prohibición

No usar similarity superficial entre tiendas como única base de promotion cross-tenant.
