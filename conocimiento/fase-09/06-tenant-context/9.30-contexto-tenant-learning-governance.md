# 9.30 — Tenant Context relevante para Learning Governance

## Objetivo

Definir qué parámetros específicos de cada ecommerce pueden afectar el nivel de governance requerido.

## Contexto relevante

### Risk tolerance
- financial;
- brand;
- customer;
- operational.

### Governance model
- approval roles;
- decision owners;
- escalation path;
- review requirements.

### Autonomy
- allowed actions;
- prohibited actions;
- approval thresholds.

### Data sensitivity
- personal data;
- commercial data;
- customer records.

### Operational maturity
- process maturity;
- auditability;
- execution discipline.

### Financial limits
- spend thresholds;
- pricing limits;
- refund limits.

### Cross-channel complexity
- number of tools;
- integrations;
- markets.

## Principio

Governance puede configurarse por tenant, pero nunca debe romper hard system guardrails.

## Prohibición

Tenant configuration no puede desactivar límites globales de seguridad, privacidad o aislamiento.
