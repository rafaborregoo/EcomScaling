# 9.10 — Contexto tenant para generalización

## Dimensiones principales

- market;
- geography;
- channel mix;
- business model;
- maturity;
- AOV;
- margin;
- product category;
- purchase frequency;
- customer segment;
- new vs returning mix;
- inventory model;
- promotional model;
- acquisition model;
- fulfilment capability;
- tracking maturity;
- seasonality.

## Source vs target

La comparación de contexto debe centrarse en variables relevantes para el mecanismo del learning.

## Context similarity

No debe reducirse a:

```text
same category
same platform
same revenue band
```

si existen diferencias estructurales materiales.

## Regla

Tenant Context aporta las variables necesarias para saber si un learning de otro contexto es reutilizable, requiere adaptación o debe validarse desde cero.
