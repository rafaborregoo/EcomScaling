# 9.21 — Tenant Context relevante para Pattern Detection

## Objetivo

Definir qué contexto específico de cada ecommerce condiciona detección e interpretación de patrones.

No se inventan valores concretos.

## Contexto relevante

### Modelo de negocio
- DTC;
- marketplace;
- suscripción;
- retail híbrido;
- B2B ecommerce.

### Canal
- paid social;
- search;
- organic;
- email;
- affiliates;
- marketplaces.

### Oferta
- catálogo;
- pricing;
- promoción;
- margen;
- AOV.

### Cliente
- segmentos;
- recurrencia;
- lifecycle;
- mercados;
- customer type.

### Operación
- inventario;
- fulfillment;
- capacidad;
- soporte;
- estacionalidad.

### Datos
- tracking;
- calidad;
- granularidad;
- attribution;
- ventanas temporales.

### Madurez
- volumen;
- estabilidad;
- capacidad de experimentación;
- disponibilidad de histórico.

### Temporalidad
- campañas;
- lanzamientos;
- Black Friday;
- temporadas;
- eventos externos.

## Principio

El mismo patrón aparente puede tener explicaciones distintas según tenant.

## Prohibición

No generalizar un patrón local sin evidencia adicional de transferibilidad.
