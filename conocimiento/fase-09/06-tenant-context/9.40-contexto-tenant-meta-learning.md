# 9.40 — Tenant Context relevante para Meta-Learning

## Objetivo

Definir qué diferencias entre tenants pueden afectar al proceso de learning.

## Contexto relevante

- data volume;
- data quality;
- execution discipline;
- outcome latency;
- experimentation frequency;
- business maturity;
- operational complexity;
- review availability;
- risk tolerance;
- strategic horizon.

## Principios

- No usar un learning process idéntico para todos los tenants si la evidencia muestra diferencias reales.
- No inventar capacidad de experimentación o data quality.
- Meta-rules tenant-specific deben permanecer en scope local salvo promoción.

## Regla

How the system learns can depend on the tenant, but tenant-specific meta-rules must remain scoped.
