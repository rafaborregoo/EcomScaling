# 9.28 — Tenant Context relevante para Anti-Learning

## Objetivo

Definir qué características específicas de cada ecommerce afectan la confiabilidad del aprendizaje.

## Contexto relevante

### Datos
- tracking quality;
- attribution;
- missingness;
- metric definitions;
- data freshness.

### Volumen
- traffic;
- orders;
- sample size;
- experiment frequency.

### Operación
- execution discipline;
- documentation;
- release process;
- concurrent changes.

### Equipo
- expertise;
- override quality;
- process consistency.

### Negocio
- seasonality;
- promotions;
- product mix;
- market volatility.

### Infraestructura
- integrations;
- migrations;
- tool reliability.

### Objetivos
- growth;
- margin;
- retention;
- cash;
- customer experience.

## Principio

La misma observación puede tener distinta calidad epistemológica según el tenant.

## Prohibición

No asumir data quality o execution fidelity uniforme entre ecommerce.
