# 9.06 — Contexto de tenant relevante para confounders

## Propósito

Identificar qué información específica de una tienda ayuda a detectar factores de confusión.

No se incluyen valores concretos de clientes.

## Contexto relevante

### Calendario comercial

- rebajas;
- lanzamientos;
- Black Friday;
- Navidad;
- promociones propias;
- eventos locales.

### Pricing

- cambios históricos;
- descuentos;
- promociones;
- bundles.

### Inventario

- stock-outs;
- reposiciones;
- disponibilidad de hero products;
- capacidad logística.

### Mix de canales

- paid;
- organic;
- direct;
- CRM;
- affiliates;
- marketplaces.

### Mix de clientes

- new;
- returning;
- VIP;
- subscriptions;
- cohorts.

### Catálogo

- lanzamientos;
- retiradas;
- nuevos bundles;
- cambios de merchandising.

### Operaciones

- shipping;
- fulfillment;
- devoluciones;
- SLA;
- mercados activos.

### Instrumentación

- pixel;
- server-side tracking;
- consent;
- analytics;
- cambios de eventos.

### Competencia y mercado

Cuando exista información disponible:

- promociones competitivas;
- shocks;
- demanda;
- cambios de categoría.

## Regla

El tenant context sirve para detectar y priorizar confounders. No debe utilizarse para inventar relaciones causales no observadas.
