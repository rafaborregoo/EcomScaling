# 9.37 — Tenant Context relevante para privacidad y aprendizaje

## Objetivo

Definir qué configuración específica del tenant afecta privacy, retention y learning eligibility.

## Contexto relevante

- data categories processed;
- jurisdictions;
- privacy requirements;
- retention periods;
- user roles;
- sensitive document classes;
- cross-tenant learning permissions;
- provider restrictions;
- internal confidentiality rules;
- deletion policies.

## Principios

- No inventar permissions.
- Default conservador cuando una permission no está definida.
- Tenant configuration no puede desactivar hard isolation.

## Regla

Privacy-sensitive behavior debe depender de configuración real y governance, no de inferencias del modelo.
