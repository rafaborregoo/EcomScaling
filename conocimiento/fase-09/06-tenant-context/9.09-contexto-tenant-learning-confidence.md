# 9.09 — Contexto tenant para Learning Confidence

## Propósito

Identificar qué elementos específicos de una tienda afectan a la estabilidad contextual de un learning.

## Contexto relevante

- mercado;
- país;
- canal;
- modelo de negocio;
- AOV;
- margen;
- producto;
- pricing;
- customer segment;
- new vs returning mix;
- inventory stability;
- promotional intensity;
- maturity;
- tracking quality;
- operating constraints;
- seasonality.

## Context stability

Debe evaluarse si el contexto actual sigue siendo suficientemente parecido al contexto en el que se generó la evidencia.

## Cambio de contexto

Un cambio material puede:

- reducir confianza práctica;
- requerir nueva validación;
- limitar reutilización.

No borra automáticamente la evidencia histórica.

## Regla

El tenant context ayuda a evaluar estabilidad y relevancia, pero no debe utilizarse para aumentar confidence sin nueva evidencia.
