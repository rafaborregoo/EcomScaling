# 9.41 — Runtime final del Learning Engine

## Pipeline maestro

### 1. Resolve Context
- tenant;
- objective;
- domain;
- current regime;
- risk.

### 2. Observe
Recoger relevant events, decisions, execution y outcomes.

### 3. Evidence Gate
Comprobar:
- data quality;
- execution fidelity;
- outcome maturity;
- provenance.

### 4. Candidate Gate
Crear learning candidate solo si existe signal suficiente.

### 5. Anti-Learning Gate
Abstenerse si:
- contaminated;
- immature;
- contradictory;
- insufficient;
- non-attributable.

### 6. Pattern / Validation
Evaluar:
- repeatability;
- support;
- coverage;
- independence;
- stability.

### 7. Contradiction Gate
Detectar conflicts y contextualizar.

### 8. Scope Gate
Clasificar:
- tenant;
- cohort;
- global;
- temporal;
- channel.

### 9. Promotion Gate
Determinar si permanece local o avanza.

### 10. Governance Gate
Aplicar:
- automatic;
- bounded;
- human review;
- approval;
- prohibited.

### 11. Application
Usar knowledge según:
- applicability;
- risk;
- current version;
- tenant context.

### 12. Outcome Loop
Capturar decision → action → execution → outcome.

### 13. Revalidation
Actualizar confidence y applicability.

### 14. Lifecycle Maintenance
- degrade;
- supersede;
- invalidate;
- dormant;
- withdraw.

### 15. Meta-Learning
Evaluar calidad del propio learning process.

## Regla runtime

**No learning bypasses evidence, scope, governance, privacy or lifecycle controls.**
