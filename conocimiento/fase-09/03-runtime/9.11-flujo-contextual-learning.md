# 9.11 — Flujo runtime de Contextual Learning

## Flujo

```text
1. identificar learning
2. obtener source context
3. obtener target/current context
4. identificar dimensiones relevantes
5. detectar moderators
6. evaluar interaction effects
7. comparar maturity
8. comparar business model / AOV / margin
9. revisar evidencia segmentada
10. decidir reuse / adapt / split / revalidate
11. asignar context-specific confidence
12. actualizar learning
```

## Reuse

Cuando el contexto relevante es equivalente y existe soporte suficiente.

## Adapt

Cuando el mecanismo parece portable pero existen diferencias materiales.

## Split

Cuando la evidencia muestra efectos diferentes por contexto.

## Revalidate

Cuando no existe evidencia suficiente para el target context.

## Regla

El runtime no debe utilizar un learning descontextualizado si conoce variables que modifican materialmente su efecto.
