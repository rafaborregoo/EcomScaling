# 9.32 — Runtime de Learning Traceability

## Objetivo

Definir cómo capturar y utilizar traceability durante el ciclo de learning.

## 1. Entity Creation

Al crear una entidad relevante:

- asignar identity;
- registrar type;
- registrar version;
- registrar scope;
- enlazar source.

## 2. Transformation Capture

Cuando una entidad deriva en otra:

- registrar relation;
- conservar upstream link;
- conservar transformation reason.

## 3. Decision Capture

Durante una decisión:

- registrar knowledge consultado;
- registrar knowledge utilizado;
- registrar policies aplicadas;
- registrar human input;
- registrar output.

## 4. Outcome Linking

Cuando llega outcome:

- enlazar con action;
- decision;
- learning loop;
- current evidence state.

## 5. Version Transition

Cuando cambia knowledge:

- preservar previous version;
- activar new version;
- mantener effective dates.

## 6. Invalidation Impact

Si knowledge se invalida:

- localizar downstream dependencies;
- marcar review required;
- evitar silent propagation.

## 7. Trace Gap Detection

Detectar:

- missing source;
- missing predecessor;
- missing outcome link;
- missing reviewer;
- missing version.

## 8. Historical Reconstruction

Permitir reconstruir:

- knowledge activo;
- context;
- policies;
- versions;
- decision.

## 9. Retrieval Integration

Cuando retrieval usa knowledge:

- conservar qué version fue recuperada;
- distinguir retrieved de actually used.

## Regla runtime

> Every material learning transition should leave a navigable trail.
