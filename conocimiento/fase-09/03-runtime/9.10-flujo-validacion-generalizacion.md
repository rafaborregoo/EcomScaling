# 9.10 — Flujo runtime para validar generalización

## Flujo

```text
1. identificar learning
2. cargar source context
3. cargar Generalization Boundary
4. identificar target context
5. comparar dimensiones relevantes
6. detectar mismatches
7. revisar moderators
8. revisar necessary/exclusion conditions
9. evaluar transfer risk
10. decidir reutilización directa o revalidación
11. registrar resultado
12. actualizar boundary si aparece nueva evidencia
```

## Reutilización directa

Solo cuando:

- target está dentro del boundary;
- no existe condición de exclusión;
- no hay drift material;
- confidence y evidencia siguen vigentes.

## Revalidación

Debe preferirse cuando:

- target está fuera del boundary;
- similarity es incierta;
- existe moderator relevante;
- transfer risk es material.

## Regla

El runtime debe tratar la aplicación fuera del boundary como una transferencia explícita, no como reutilización silenciosa.
