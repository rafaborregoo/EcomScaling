# 9.18 — Flujo runtime de calibración

## Flujo

```text
1. identificar benchmark/threshold/guardrail
2. cargar versión y contexto
3. recopilar triggers
4. clasificar outcomes posteriores
5. revisar false positives
6. revisar false negatives
7. revisar near misses
8. revisar prevented incidents
9. ponderar severity y operational cost
10. revisar benchmark validity
11. detectar context drift
12. evaluar calibration
13. proponer cambio o no-change
14. enviar a governance si procede
15. medir nueva versión
```

## Durante ejecución

El runtime aplica el guardrail vigente.

## Durante learning

El sistema puede recomendar calibración.

## Regla

```text
LEARNING
CAN INFORM
GOVERNANCE

LEARNING
CANNOT
SELF-MODIFY CRITICAL CONTROL
```
