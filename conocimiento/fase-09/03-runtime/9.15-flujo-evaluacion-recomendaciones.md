# 9.15 — Flujo runtime para evaluar recomendaciones

## Flujo

```text
1. registrar problema y recomendación
2. registrar evidencia y contexto
3. registrar expected impact / risk
4. registrar human response
5. identificar accepted / rejected / modified
6. comprobar si se ejecuta
7. registrar versión ejecutada
8. evaluar execution fidelity
9. esperar outcome maturity
10. evaluar outcome y attribution
11. evaluar recommendation quality ex ante
12. evaluar outcome ex post
13. revisar calibración
14. registrar learning
15. gestionar supersession si aplica
```

## Non-executed

No atribuir outcome a la recomendación.

## Modified

Evaluar por separado recomendación original y acción final.

## Superseded

No mantener una recomendación antigua como vigente si el contexto o evidencia ya cambió.

## Regla

El runtime debe conservar toda la cadena desde recomendación hasta evaluación final.
