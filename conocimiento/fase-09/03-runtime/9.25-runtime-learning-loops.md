# 9.25 — Runtime de Learning Loops

## Objetivo

Definir cómo abrir, mantener, cerrar, reabrir y aplicar ciclos de aprendizaje.

## 1. Loop initiation

Abrir loop cuando exista:

- decisión relevante;
- intervención;
- experimento;
- incident;
- override;
- playbook execution.

## 2. Pre-execution capture

Registrar:

- context;
- hypothesis;
- recommendation;
- expected outcome;
- maturity window.

## 3. Execution tracking

Durante ejecución:

- verificar fidelity;
- registrar modificaciones;
- bloquear learning si no hubo ejecución suficiente.

## 4. Outcome wait

Si outcome aún no madura:

- mantener loop abierto;
- no forzar conclusión;
- registrar expected maturity.

## 5. Evaluation gate

Antes de cerrar:

- validar outcome;
- attribution;
- confounders;
- execution fidelity;
- evidence quality.

## 6. Closure

Cerrar como:

- learned;
- inconclusive;
- failed execution;
- invalidated;
- superseded.

## 7. Learning application

El learning puede:

- ajustar confidence;
- modificar priorización;
- informar recomendación;
- generar candidate;
- solicitar governance review.

## 8. Reopening

Reabrir si:

- aparece nueva evidencia;
- outcome cambia;
- surge contradiction;
- se detecta measurement error.

## 9. Nested loops

Debe preservarse relación entre:

- micro;
- meso;
- macro loops.

## 10. Stabilization

Si existe positive feedback amplification:

- limitar exposure;
- introducir review;
- mantener exploration.

## Regla runtime

> No cierres el loop hasta que sepas qué se hizo y qué ocurrió.
