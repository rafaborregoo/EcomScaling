# 9.40 — Runtime de Meta-Learning

## Flujo conceptual

1. Observar learning episodes.
2. Capturar success/failure del learning process.
3. Clasificar error attribution.
4. Medir confidence calibration.
5. Detectar blind spots y learning debt.
6. Comparar learning velocity, quality y yield por domain.
7. Generar meta-learning candidate.
8. Aplicar Anti-Learning sobre el meta-claim.
9. Comprobar scope y domain specificity.
10. Proponer process adjustment.
11. Aplicar governance gate.
12. Medir outcome del cambio.
13. Revalidar o rollback.

## Regla runtime

**Learn from the learning process, but govern every material change to that process.**
