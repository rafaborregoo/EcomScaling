# 9.17 — Flujo runtime de aprendizaje sobre Playbooks

## Flujo

```text
1. identificar objetivo
2. seleccionar playbook/version
3. validar preconditions
4. seleccionar branch
5. registrar planned sequence
6. ejecutar steps
7. registrar deviations
8. comprobar completion
9. medir outcome
10. esperar maturity
11. evaluar playbook effectiveness
12. evaluar step evidence
13. evaluar sequence/dependencies
14. detectar execution sensitivity
15. actualizar playbook learning
16. proponer version update si procede
```

## Si falta evidencia por step

Mantener:

```text
UNKNOWN
```

No repartir el éxito del playbook.

## Si cambia el contexto

Reevaluar:

- branch;
- preconditions;
- applicability.

## Regla

El runtime debe registrar la ejecución real del playbook, no asumir que se siguió el diseño original.
