# 9.38 — Runtime de Long-Term Learning

## Flujo conceptual
1. Clasificar memory horizon, temporal layer, scope y volatility.
2. Detectar cuándo episodes repetidos justifican consolidation.
3. Comprimir preservando scope, uncertainty, exceptions y provenance.
4. Programar revalidation según volatility, risk y last confirmation.
5. Detectar structural breaks.
6. Degradar applicability del knowledge afectado.
7. Mover knowledge fuera de contexto a dormant.
8. Reactivar solo tras current context match.
9. Recuperar knowledge compatible con el regime actual.
10. Aplicar retention y privacy gates antes de persistencia prolongada.

## Regla runtime
**Consolidate history, revalidate knowledge, and preserve regime context.**
