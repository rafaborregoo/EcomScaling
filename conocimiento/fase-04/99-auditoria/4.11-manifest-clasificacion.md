## 3. Redundancia consolidada

Se han condensado múltiples ejemplos y anti-patterns alrededor de:

- more work ≠ more value;
- activity ≠ throughput;
- top-ranked set ≠ best portfolio;
- adding priority ≠ adding capacity;
- active ≠ approved;
- rank ≠ state;
- importance ≠ execution order;
- individual feasibility ≠ joint feasibility;
- project count ≠ priority count;
- stopping ≠ failure;
- diversification ≠ project count;
- 100% utilization ≠ maximum throughput.
