# FASE 7.4 — Contexto del tenant para impacto esperado

## Propósito

Expected impact solo tiene sentido en contexto.

Este artefacto recoge categorías de información específica del ecommerce que pueden amplificar, limitar o cambiar el valor esperado.

No contiene datos concretos.

---

## 1. Primary Objective

Puede incluir:

- growth;
- profitability;
- contribution;
- cash;
- resilience;
- learning;
- capacity;
- expansion.

El impacto es relativo al objetivo.

---

## 2. Objective Hierarchy

Un negocio puede perseguir simultáneamente:

- growth;
- profit;
- cash;
- resilience.

Debe existir jerarquía.

---

## 3. Strategic Mode

Conceptualmente:

```text
Survive
Stabilize
Optimize
Scale
Expand
```

Cada modo cambia qué impacto es valioso.

---

## 4. Baseline

Debe poder conocerse:

- performance actual;
- historical baseline;
- previous best;
- recent deterioration;
- baseline volatility.

---

## 5. Relevant Base

- traffic;

- customers;
- revenue;

- SKU share.

## 6. Headroom

Puede inferirse a partir de:

- previous performance;
- current deterioration;
- structural constraints;
- own baseline;
- contextual benchmarks.
