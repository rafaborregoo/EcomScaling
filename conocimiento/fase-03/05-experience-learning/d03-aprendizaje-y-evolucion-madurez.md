# Fase 03 · D03 — Experience & Learning de madurez

## Propósito

D3 contiene contenido explícito de aprendizaje porque la madurez incluye feedback loops, outcome evidence, evolución del perfil, postmortems, repositorios de tests y revisión de precisión.

---

## 1. Maturity profile evolution

El perfil de madurez puede actualizarse con nueva evidencia.

Debe distinguirse:

- cambio real de capability;
- reducción de incertidumbre;
- aumento de confidence.

Ejemplo:

- Week 1: Finance E3–E5, confidence LOW;
- Week 4: Finance E4, confidence HIGH.

Esto puede representar mejor observación, no necesariamente mejora real.

---

## 2. Advancement evidence

Una capability debe avanzar cuando aparecen comportamientos estructurales observables.

Ejemplos:

- structured testing;
- pipeline;
- ownership;
- measured performance;
- feedback;
- forecasting;
- resilience.

El ascenso debe justificarse por evidencia, no por autodeclaración.

---

## 3. Regression evidence

Una capability puede perder madurez si desaparecen durante un periodo prolongado:

- procesos;
- personas clave;
- sistemas usados;
- medición;
- calidad de datos;
- ownership.

Debe distinguirse de fallos temporales.

---

## 4. Outcome evidence

Una capability madura debería producir outcomes observables.

Ejemplo para forecasting:

- forecast exists;
- accuracy measured;
- errors analyzed;
- forecast influences decisions.

El aprendizaje requiere relacionar capacidad con comportamiento observable.

---

## 5. Feedback loops

Ciclo de madurez:

> action → result → measurement → learning → adjustment

Cuanto más institucionalizado está este ciclo, mayor learning maturity.

---

## 6. Learning maturity

Puede observarse mediante:

- postmortems;
- test repositories;
- creative learnings;
- forecast accuracy reviews;
- campaign learnings.

---

## 7. Knowledge institutionalization

La madurez aumenta cuando el conocimiento pasa de:

- PERSON

a:

- SYSTEM.

Esto reduce founder dependency y key-person dependency.

---

## 8. Resilience learning

La resiliencia madura incluye:

- detectar;
- contener;
- recuperar;
- aprender;
- prevenir recurrencia.

Las señales observables incluyen:

- detection time;
- response time;
- recovery time;
- postmortem;
- prevention.

---

## 9. Experience retention

D3 implica que el sistema debería poder conservar evidencia histórica de:

- maturity assessments;
- capability changes;
- transition events;
- advancement;
- regression;
- outcomes;
- feedback loops.

El documento no define todavía el schema técnico de esta memoria.

---

## 10. Límites

La fuente no define:

- decay automático;
- knowledge promotion;
- aprendizaje cross-tenant;
- actualización automática de pesos;
- reinforcement learning;
- generalización automática entre empresas.

Estos mecanismos no deben inventarse.
