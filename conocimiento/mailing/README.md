# Conocimiento de mailing

Espacio de trabajo para reunir la información de mailing que se incorporará al conocimiento del copiloto y de los agentes de análisis y creación.

El contenido se organizará en fases más adelante. Por ahora, este directorio sirve como punto de partida para recopilar principios, voz de marca, audiencias, campañas, automatizaciones, entregabilidad, cumplimiento y ejemplos.
