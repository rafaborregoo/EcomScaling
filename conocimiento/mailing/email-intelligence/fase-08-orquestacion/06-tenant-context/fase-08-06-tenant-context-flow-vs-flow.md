# Fase 8.6 — Flow vs Flow — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir los parámetros propios del ecommerce necesarios para `Flow vs Flow`.

- `flow_mutex_groups`
- `flow_priority_order`

## Principio

No deben hardcodearse como reglas universales.
