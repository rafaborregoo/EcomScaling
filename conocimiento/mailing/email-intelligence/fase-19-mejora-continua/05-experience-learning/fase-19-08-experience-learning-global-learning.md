# Fase 19.8 — Global Learning

## Tipo de artefacto
`05-experience-learning`

## Objetivo

Global Learning contiene patrones suficientemente generales como para informar razonamiento transversal.

Debe ser la capa con mayor exigencia de promoción.

No debe contener:
- nombres de tenants;
- métricas privadas;
- información identificable;
- reglas absolutas derivadas de pocos casos.

Los aprendizajes globales deben expresarse como principios contextualizados y revisables.

---

## Flujo de aprendizaje

```text
RESULT
→ NORMALIZE
→ OBSERVE
→ HYPOTHESIZE
→ TEST / VALIDATE
→ EVIDENCE
→ LEARNING
→ PROMOTE / DEPRECATE
→ REVIEW
```

---

## Reglas

- conservar contexto;
- conservar evidence lineage;
- separar correlación y causalidad;
- expresar scope;
- expresar confidence;
- mantener contradicciones;
- no borrar resultados negativos;
- no convertir un resultado aislado en regla universal.

---

## Principio maestro

El sistema mejora cuando transforma resultados en conocimiento trazable, no cuando acumula más datos.
