# Fase 19.10 — Promoción de conocimiento

## Tipo de artefacto
`05-experience-learning`

## Objetivo

Promover conocimiento significa mover un learning candidate hacia un nivel de reutilización superior.

Flujo conceptual:
```text
OBSERVATION
→ TENANT LEARNING
→ CATEGORY LEARNING
→ GLOBAL LEARNING
```

La promoción no debe ser automática.

Debe evaluar:
- evidence quality;
- replicación;
- scope;
- privacidad;
- contradicciones;
- actualidad;
- revisión humana cuando corresponda.

---

## Flujo de aprendizaje

```text
RESULT
→ NORMALIZE
→ OBSERVE
→ HYPOTHESIZE
→ TEST / VALIDATE
→ EVIDENCE
→ LEARNING
→ PROMOTE / DEPRECATE
→ REVIEW
```

---

## Reglas

- conservar contexto;
- conservar evidence lineage;
- separar correlación y causalidad;
- expresar scope;
- expresar confidence;
- mantener contradicciones;
- no borrar resultados negativos;
- no convertir un resultado aislado en regla universal.

---

## Principio maestro

El sistema mejora cuando transforma resultados en conocimiento trazable, no cuando acumula más datos.
