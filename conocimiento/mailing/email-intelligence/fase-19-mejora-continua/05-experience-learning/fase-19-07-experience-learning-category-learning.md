# Fase 19.7 — Category Learning

## Tipo de artefacto
`05-experience-learning`

## Objetivo

Category Learning recoge patrones que aparecen de forma consistente dentro de una categoría de negocio o producto.

Debe exigir evidencia diversa y no una única tienda.

El aprendizaje debe especificar:
- categoría;
- condiciones;
- rango de aplicación;
- evidencia;
- confidence;
- excepciones.

Puede informar estrategias futuras sin convertirse en mandato.

---

## Flujo de aprendizaje

```text
RESULT
→ NORMALIZE
→ OBSERVE
→ HYPOTHESIZE
→ TEST / VALIDATE
→ EVIDENCE
→ LEARNING
→ PROMOTE / DEPRECATE
→ REVIEW
```

---

## Reglas

- conservar contexto;
- conservar evidence lineage;
- separar correlación y causalidad;
- expresar scope;
- expresar confidence;
- mantener contradicciones;
- no borrar resultados negativos;
- no convertir un resultado aislado en regla universal.

---

## Principio maestro

El sistema mejora cuando transforma resultados en conocimiento trazable, no cuando acumula más datos.
