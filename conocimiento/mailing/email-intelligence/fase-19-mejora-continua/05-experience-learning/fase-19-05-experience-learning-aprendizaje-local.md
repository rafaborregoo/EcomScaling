# Fase 19.5 — Aprendizaje local

## Tipo de artefacto
`05-experience-learning`

## Objetivo

El aprendizaje local resume evidencia válida principalmente para un tenant concreto.

Debe preservar:
- scope;
- contexto;
- evidence;
- confidence;
- exceptions;
- vigencia.

Tiene prioridad práctica sobre heurísticas genéricas cuando la evidencia local es suficiente, pero no debe convertirse automáticamente en regla global.

---

## Flujo de aprendizaje

```text
RESULT
→ NORMALIZE
→ OBSERVE
→ HYPOTHESIZE
→ TEST / VALIDATE
→ EVIDENCE
→ LEARNING
→ PROMOTE / DEPRECATE
→ REVIEW
```

---

## Reglas

- conservar contexto;
- conservar evidence lineage;
- separar correlación y causalidad;
- expresar scope;
- expresar confidence;
- mantener contradicciones;
- no borrar resultados negativos;
- no convertir un resultado aislado en regla universal.

---

## Principio maestro

El sistema mejora cuando transforma resultados en conocimiento trazable, no cuando acumula más datos.
