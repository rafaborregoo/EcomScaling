# Fase 3.20 — Send vs No-Send — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir los datos y políticas específicos del ecommerce necesarios para `Send vs No-Send`.

## Configuración

- `send_decision_policy`
- `minimum_audience_size`
- `pressure_limits`
- `margin_floor`
- `blackout_dates`

## Regla

Estos valores pertenecen a la tienda.

No deben convertirse en constantes universales dentro del RAG ni ser inventados por el modelo.
