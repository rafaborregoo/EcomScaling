# Fase 2.28 — Waitlist — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Waitlist`.

## Configuración

- `waitlist_source`
- `variant_specific_waitlist`
- `priority_policy`
- `waitlist_expiry`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
