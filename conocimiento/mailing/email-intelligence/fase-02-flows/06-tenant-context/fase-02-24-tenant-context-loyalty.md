# Fase 2.24 — Loyalty — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Loyalty`.

## Configuración

- `loyalty_program_enabled`
- `loyalty_source_of_truth`
- `tiers`
- `benefits`
- `points_expiry_rules`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
