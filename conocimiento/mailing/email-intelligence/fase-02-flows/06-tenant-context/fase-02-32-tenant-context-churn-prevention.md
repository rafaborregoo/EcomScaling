# Fase 2.32 — Churn Prevention — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Churn Prevention`.

## Configuración

- `churn_risk_definition`
- `risk_thresholds`
- `category_cycles`
- `retention_constraints`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
