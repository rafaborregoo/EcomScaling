# Fase 2.25 — VIP Flow — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `VIP Flow`.

## Configuración

- `vip_definition`
- `vip_tiers`
- `vip_benefits`
- `vip_exclusions`
- `manual_override_policy`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
