# Fase 2.33 — Conflictos entre flows — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Conflictos entre flows`.

## Configuración

- `flow_priority_order`
- `mutex_groups`
- `support_priority`
- `transactional_priority`
- `offer_conflict_policy`
- `pressure_precedence`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
