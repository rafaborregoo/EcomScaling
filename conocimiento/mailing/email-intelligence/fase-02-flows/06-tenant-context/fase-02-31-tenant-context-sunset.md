# Fase 2.31 — Sunset — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Sunset`.

## Configuración

- `sunset_window`
- `max_reengagement_attempts`
- `marketing_suppression_policy`
- `reactivation_policy`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
