# Fase 2.29 — Win-Back — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Win-Back`.

## Configuración

- `winback_window`
- `max_attempts`
- `eligible_segments`
- `promotion_limits`
- `post_winback_policy`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
