# Fase 2.26 — Back in Stock — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Back in Stock`.

## Configuración

- `inventory_source`
- `variant_tracking`
- `regional_availability`
- `restock_minimum_quantity`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
