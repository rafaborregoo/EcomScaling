# Fase 2.27 — Price Drop — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la configuración específica de cada ecommerce necesaria para operar `Price Drop`.

## Configuración

- `price_source`
- `minimum_price_drop`
- `excluded_products`
- `promotion_policy`
- `reference_price_policy`

## Principio

Estos valores pertenecen a la tienda. No deben convertirse en reglas universales dentro del RAG.
