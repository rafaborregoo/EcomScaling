# Fase 9.20 — Construcción de marca — Tenant Context

## Tipo de artefacto
`06-tenant-context`

## Objetivo

Definir la información específica de esta tienda necesaria para `Construcción de marca`.

## Datos del tenant

- `brand_positioning`
- `category_strategy`
- `brand_story`
- `customer_experience_principles`
- `long_term_merchandising_strategy`

---

## Source of Truth

La información debe proceder de:
- ecommerce;
- proveedor;
- carrier;
- soporte;
- catálogo;
- políticas aprobadas;
según corresponda.

No debe reconstruirse mediante inferencia del LLM cuando exista una fuente operativa.

---

## Principio maestro

El tenant context describe la realidad concreta de la operación.
