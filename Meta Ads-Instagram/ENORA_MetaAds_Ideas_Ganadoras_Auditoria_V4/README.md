# e-NORA — Vídeo 04 · Big idea, patrones y dos rutas de investigación creativa

## Qué incluye
ZIP de conocimiento **candidato** con transcripción de origen, 10 fichas RAG, contratos propuestos, playbooks, guardarraíles, modelo de experimento, dependencias de datos y auditoría comparativa V01–V04.

## Qué aporta de verdad
1. Separar idea central comercial de formato/hook.
2. Buscar patrones contrastables en resultados de creativos propios.
3. Extraer y reinterpretar ideas existentes en ejecuciones distintas.
4. Usar el contenido orgánico para identificar hipótesis cuando no hay histórico suficiente.
5. Priorizar coste, facilidad, rapidez de aprendizaje y evidencia.
6. Distinguir personas atendidas de oportunidades no probadas, sin inventar perfiles sensibles.
7. Mantener aprendizajes con fuente y versión, solo para su tenant.

## Qué NO incluye
SOP original completo, archivos de vídeo ni anuncios, datasets de rendimiento, screenshots ni guía completa de rodaje/edición. No hay auditoría real de repositorio ni implementación.

## Uso recomendado — NO INTEGRAR TODAVÍA
1. Extraer ZIP **fuera de carpetas de ingestión automática del proyecto**.
2. Abrir `00_PROMPT_MAESTRO_AUDITORIA_INCREMENTAL.md` en Claude Code con acceso de lectura al repositorio.
3. Adjuntar V01/V02/V03 o sus auditorías si disponibles; si no, exigir comparación parcial explícita.
4. Solicitar informe con matriz de evidencias, duplicados, dependencias, propuestas y riesgos.
5. Traer resultado a esta conversación para decidir qué fusionar, descartar o desarrollar antes de tocar RAG.
