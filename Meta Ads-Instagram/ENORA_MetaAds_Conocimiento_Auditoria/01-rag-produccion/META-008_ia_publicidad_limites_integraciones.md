# META-008 | Aplicaciones de IA a Meta Ads y límites

**Estado:** candidato. **Fuente:** [VÍDEO] ~30:55–32:57.

## Tres categorías propuestas en la fuente

- **Analizar:** interpretar información de campañas y del negocio.
- **Hacer:** asistir en tareas de operación; la herramienta exacta y permisos dependen del proveedor.
- **Crear:** imágenes o vídeos para anuncios.

El vídeo menciona ChatGPT para dudas/pantallazos, Triple Whale para datos conectados, Manus para acciones generales e Higgsfield para generación creativa. Las afirmaciones de capacidades/ventajas son testimoniales y no una evaluación comparativa, contrato de API ni recomendación de integrar estas herramientas.

## Aplicación a e-NORA [PROPUESTA]

- Primero asegurar datos confiables y permisos por tenant.
- Recuperar conocimiento sobre qué significa una métrica; usar herramientas/cálculos para cifras y fuentes.
- Generar diagnósticos explicables y recomendaciones sin realizar acciones externas silenciosas.
- Si se ofrece creación de vídeos, tratarla como iniciativa separada, con revisión humana, derechos de uso y validación de claims; **este vídeo no enseña a producirlos**.

## Riesgos

Alucinaciones comerciales, costes no medidos, datos privados de tiendas, fuga entre tenants, accesos excesivos, modificación no autorizada de campañas, uso de imágenes/audio con derechos, afirmaciones publicitarias engañosas, texto generativo no revisado.

## Auditoría requerida

Identificar agentes IA existentes, herramientas disponibles, motores de reglas, separación de tenants, permisos, logging y cualquier módulo de creativo/video. No inferir que un producto externo conectado existe dentro de e-NORA.
