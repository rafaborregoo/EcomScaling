# Taxonomía candidata para creativos — sujeto a contrato canónico del repo

## Diferencias semánticas que el agente debe preservar

| Entidad | Significado | Ejemplo abstracto |
|---|---|---|
| Objetivo de negocio | Resultado económico perseguido | Incrementar primeras compras rentables |
| Persona/Job-to-be-done | Necesidad/uso hipotético, no dato demográfico verificado | Busca una solución rápida |
| Objeción | Barrera que mencionan consumidores | «No sé si compensa el precio» |
| Pilar | Territorio de comunicación recurrente | Conveniencia |
| Ángulo | Argumento de persuasión para ese territorio | Ahorras tiempo de preparación |
| Concepto | Idea narrativa o pieza concreta | Comparación del proceso actual y el nuevo |
| Hook | Elemento de apertura para captar interés | Una pregunta problemática |
| Formato | Estructura/estética/medio | Demostración UGC; imagen estática |
| Etapa de conciencia | Grado de conocimiento del problema/solución/producto | Conoce problema, no soluciones |
| Objetivo Meta | Optimización configurada en campaña | Sales |
| Placement | Superficie de entrega | Reels/Stories/Feed |
| Hipótesis de prueba | Cambio esperado y cómo medirlo | Mayor tasa de compras con mensaje X |

## Clasificación

- Usar una taxonomía versionada y mapeable a IDs reales que existan en e-NORA.
- Clasificación múltiple si corresponde, con incertidumbre registrada.
- Identificar `unknown`, no asignar todas las celdas por defecto.
- Evitar «diversificar formatos» como sustituto de diversidad de ángulos y personas.

## Límite del vídeo

No aporta definiciones formales exhaustivas de cada etapa de conciencia ni criterios analíticos para clasificar formatos mediante visión IA. **Este documento es diseño propuesto**, no transcripción del modelo de la ponente.
