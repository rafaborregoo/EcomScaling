# Experimentos creativos en presupuestos limitados

**Estado:** propuesta de aprendizaje para e-NORA, **no un manual de creación de vídeos extraído del vídeo**.

## Ideas del vídeo [FUENTE]

- Adaptar mensaje a subsegmentos valiosos (~06:00–12:20).
- Investigar ejemplos en Meta Ads Library (~12:22–15:38).
- Usar engagement orgánico como una señal de ideas para anuncios de pago, sin asegurar traducción (~18:08–20:00).
- Una herramienta patrocinada dice generar variaciones, formatos y convertir imágenes a vídeo (~08:22–09:53): afirmaciones comerciales no verificadas.

## Flujo de experimentación [PROPUESTA e-NORA]

`insight → hipótesis → variante identificable → test (si hay muestra) → resultado → incertidumbre → biblioteca de aprendizajes`.

**Ficha conceptual**:

| Campo | Función |
|---|---|
| `idea_origin` | Datos propios, orgánico, competencia, equipo |
| `creative_angle` | Objeción, beneficio, demostración, testimonio autorizado |
| `customer_problem` | Problema comercial identificado, no atributos sensibles |
| `hypothesis` | Razón comercial de la prueba |
| `creative_asset_ref` | Referencia a activo verificable cuando exista |
| `test_design` | Ventana, presupuestos, segmentación, unidad comparada |
| `outcome` | CPA/ROAS/contribución con fechas y límites |
| `quality_flags` | Baja muestra, sesgo, atribución, cambios simultáneos |

## Distinción de tres funcionalidades

1. **Análisis de métricas de creativos:** puede operar si Meta proporciona métricas por anuncio.
2. **Análisis audiovisual del contenido:** solo si hay asset/frames/audio disponibles de forma autorizada y realmente procesados.
3. **Producción de vídeos:** requiere conocimientos adicionales (guion, grabación, edición, generación audiovisual, derechos) y una implementación específica. Ninguna de las dos anteriores garantiza la tercera.

## Tareas de conocimiento faltante

Investigación de audiencias y objeciones; estructura de hooks; storyboard, tomas/B-roll, sonido, montaje, variantes y métricas de retención; validación de claims; derecho de imagen, UGC y contenidos generados con IA. Buscar fuentes adicionales, no atribuirlas a este vídeo.

## No demostrar falsamente

Un hook con más engagement no ha demostrado mejorar conversión. Un anuncio longevo en Ads Library no ha demostrado ROI. Un vídeo generado por IA no es automáticamente apto para publicidad ni acredita veracidad de testimonios.
